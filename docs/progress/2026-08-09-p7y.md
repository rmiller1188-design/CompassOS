# 2026-08-09 — P7Y unified multi-account sync coordinator

- Added a provider-neutral coordinator that fans incremental mail, calendar, and contacts sync across multiple active Google and Microsoft connected accounts.
- Added strict duplicate-account, provider, resource, and page-limit validation before provider work.
- Isolated account failures so one mailbox/account does not prevent other connected accounts from syncing.
- Reauthorization failures stop subsequent resources only for the affected account, preventing redundant provider calls while preserving progress elsewhere.
- Inactive accounts are skipped before adapter resolution.
- Coordinator summaries expose bounded operational status without copying raw provider error messages into the result envelope.
- Added deterministic coverage for multi-account success, partial failure, reauthorization isolation, inactive accounts, adapter failures, resource de-duplication, and fail-closed provider/account validation.
- Added the coordinator to the production-core validation script and bumped the package to 0.42.0.

Live Google/Microsoft account fanout, OAuth-backed adapter resolution, Supabase persistence, provider throttling, and concurrent scheduler execution remain infrastructure-blocked and are not claimed as validated.
